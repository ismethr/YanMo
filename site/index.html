功能

写论文，而不是找东西

把一篇论文当成一个项目来管理：章节、图表、文献和编译结果都在手边，引用出错会在写的时候就被发现。

零配置编译

内置 Tectonic 引擎，不必先安装几个 GB 的 TeX 发行版；已有 TeX Live 也能直接使用。可从期刊模板起步、与 Overleaf 互相导入导出；草稿模式让大图论文编译更快；还能用 Pandoc 一键导出 Word。

论文大纲

跨文件解析章节结构，中英文字数分开统计；拖动即可调整章节顺序，子节随之移动，\input 也会自动调整。

图表资产

所有图、表、公式集中列出：标题、label、被引用次数、图片文件是否存在，一眼看全。

文献管理

BibTeX 文献库可搜索，标出引用了却不存在、从未引用、重复的条目；粘贴 DOI、arXiv 编号或直接搜索 Zotero 即可导入；一键核对每条文献是否真实、信息是否一致。

可控的 AI

润色、翻译、解释编译错误、修复引用。自带 Key：Claude、OpenAI 兼容接口或本地 Ollama。所有改动以 diff 呈现，确认后才写入。

对 Agent 友好

界面、命令行与 MCP 共用同一套命令。运行 ym mcp，Claude Code 等编程 Agent 就能读大纲、跑检查、编译论文。

ym check

一条命令，检查整篇论文

编辑器里的问题面板和命令行用的是同一套检查，也能放进 CI，投稿前自动把关。

  • 未定义的 \ref 与 \cite
  • 重复的 label、缺失的图片文件
  • 从未被引用的图表与文献条目
  • 有错误时退出码非 0，输出可选 JSON
$ ym check
sections/intro.tex:3: error[undefined_ref] 引用了未定义的 label `fig:missing`
sections/intro.tex:4: error[undefined_cite] 引用了不存在的文献 `nobody2099`
sections/method.tex:4: error[missing_file] 找不到文件 `figures/arch.pdf`
sections/method.tex:7: error[duplicate_label] label `sec:intro` 被定义了 2 次
refs.bib:8: warning[unused_bib_entry] 文献 `unused2020` 从未被引用
sections/method.tex:2: warning[unreferenced_asset] 图 `fig:arch` 从未被引用

4 个错误，2 个警告
原则

你的论文，始终是你的

开源免费

MIT 或 Apache-2.0 双许可，代码完全公开，欢迎参与。

本地优先

论文就是普通文件夹里的 .tex 与 .bib，不锁定格式，随时可以换回别的编辑器。

自带 Key

研墨不经手你的密钥和论文；不想联网，就用本地模型。

中文友好

中文字数统计、ctex 模板、XeLaTeX 默认配置，开箱即用。

开发进度

预览版 v0.4.0 已发布，下一步计划如下。

  1. 结构解析与检查已完成

    容错的 LaTeX 结构解析器、文献解析与 ym check 命令行。

  2. 桌面应用外壳已完成

    编辑器、大纲、图表、文献与问题面板，统一命令注册表。

  3. 编译与 PDF 预览已完成

    内置 Tectonic、编译日志定位、SyncTeX 双向跳转、Pandoc 导出 Word。

  4. 结构化管理增强已完成

    DOI / arXiv 一键导入、拖入或粘贴图片自动插入、图表缩略图与编号。

  5. AI 辅助已完成

    自带 Key（Claude、DeepSeek、Ollama 等）、选区润色与翻译、对比确认后才写入。

  6. v0.1 发布已发布

    macOS、Windows、Linux 安装包，内置编译引擎。

  7. v0.1.1 英文界面已发布

    界面、检查结果、错误提示与命令行支持中英文切换。

  8. v0.2 Agent 接入与自动更新已发布

    MCP 接口、拖动调整章节顺序、自动更新。

  9. v0.3 文献与结构已发布

    Zotero 集成、文献核查与 AI 引用核查、一键把章节拆成独立文件。

  10. v0.4 模板与编译已发布

    期刊模板、Overleaf 导入导出、设置窗口、编译停止与草稿模式。

  11. v0.5规划中

    公式悬停预览、整篇 AI 审稿、Git 面板、安装包签名与公证。
